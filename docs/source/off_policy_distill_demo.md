# Off-Policy Distillation Demo

本文档介绍如何使用 G-Core V4 进行文本模型的离线策略蒸馏 (Off-Policy Knowledge Distillation)。

This document introduces how to use G-Core V4 for off-policy knowledge distillation on text-only models.

## Overview / 概览

Off-Policy Distillation 与 On-Policy 的区别：

| | On-Policy | Off-Policy |
|---|-----------|------------|
| **Rollout 来源** | 学生模型在线生成 | 教师模型预生成 |
| **训练效率** | 较慢（需在线采样） | 较快（离线数据） |
| **数据质量** | 学生水平 | 教师水平 |
| **适用场景** | 学生已有一定能力 | 从零训练基座模型 |

Off-Policy 使用教师模型生成的高质量 rollout 作为训练数据，结合教师 KL 惩罚进行训练。

Off-policy uses high-quality rollouts generated by the teacher model as training data, combined with teacher KL penalty for training.

## Quick Start / 快速开始

```bash
cd gcore-dev
bash tasks/off_policy_distill/scripts/off_policy_distill.sh
```

核心启动命令：

```bash
export PYTHONPATH="$PWD:/root/Megatron-LM:/root/mbridge:/root/Megatron-Bridge/src:$PYTHONPATH"

# 初始化 Ray 集群
source tasks/off_policy_distill/scripts/mpirun-init-ray.sh

# 启动蒸馏训练
python3 -u gpatch_v4/entry/train_off_policy_distill.py \
    --config-path="../../tasks/off_policy_distill/yaml" \
    --config-name="offpd_test_multi_data.yaml"
```

## Configuration / 配置

```yaml
training:
  enable_teacher_rollout: True     # 教师生成 rollout
  enable_teacher_kl_loss: True     # 启用教师 KL 惩罚

# 学生模型: Qwen3-1.7B-Base
policy:
  model_arch: "qwen3"
  hf_model_path: "hf-hub/Qwen/Qwen3-1.7B-Base"

# 教师模型: Qwen3-32B
teacher:
  model_arch: "qwen3"
  hf_model_path: "hf-hub/Qwen/Qwen3-32B"

# 数据集: NuminaMath-CoT
data:
  data_pathes:
    - "hf-hub/AI-MO/NuminaMath-CoT-jsonl"
  py_path: "tasks/off_policy_distill/simple_dataset.py"
  fn_name: "get_dataset_and_dataloader"

# 优化器: cosine 衰减
optimizer:
  lr: 2e-5
  lr_decay_style: "cosine"
  lr_warmup_steps: 100
```

## Customization / 自定义扩展

1. **YAML 配置** — 替换学生/教师模型路径、调整数据集路径
2. **Dataset** — 参考 `tasks/off_policy_distill/simple_dataset.py`
   - 支持 `get_dataset_and_dataloader()`（训练集）
   - 支持 `get_eval_dataset_and_dataloader()`（评测集）
3. **Reward** — 参考 `tasks/off_policy_distill/bt_reward.py`
